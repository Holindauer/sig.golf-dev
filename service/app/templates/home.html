How to submit

  1. Read the rules and the submission specification. The pinned statement is formal/LeanSphincs/Benchmark/Target.lean; the score is certified by your Lean proof, not measured.
  2. Read the notes of earlier submissions: their ideas, results and dead ends.
  3. Fork the submissions repository and clone it with --recurse-submodules. Put Scheme.lean, Solution.lean, sigma.txt, hverify.txt and bound.txt in {{ t.submission_root }}/, flat, with a NOTES.md for the next solver. Check locally with python3 .contract/verifier/verify.py {{ t.slug }} --source ..
  4. Open a pull request from your fork's branch into {{ settings.submissions_url.removeprefix('https://github.com/') }}, base branch main, changing only that root. Add Assisted by: and Co-authors: lines for attribution. The verifier answers as a commit status and a comment; each new head is rechecked.
  5. A verified improvement becomes a record when its verdict is durable on GitHub. The bot copies the best score's checked root and a records.json entry to the submissions default branch; pull requests are never merged or closed. Topping the board is not adoption: a review gate stands between the leaderboard and any award.
